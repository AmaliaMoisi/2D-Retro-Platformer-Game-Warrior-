# Warrior - 2D Retro Platformer Game

A 2D side-scrolling retro platformer game built from scratch using **Python** and **Pygame**. The project showcases Object-Oriented Programming (OOP) principles, custom physics calculations, dynamic asset loading pipelines, and state management.

## 🎮 Features
- **Custom Physics Engine:** Implements simulated gravity, variable fall counts, and responsive double-jump mechanics.
- **Dynamic Sprite Sheet Pipeline:** Automated script that processes, scales, and mirrors multi-frame character sheets (`Idle`, `Run`, `Hit`) at runtime.
- **State & Time Management:** Real-time countdown timer system, live tracking mechanics, and player respawning protocols.
- **Immersive Audio:** Integrated `pygame.mixer` for looping ambient background tracks and overlapping sound triggers.

## 🛠️ Tech Stack & Concepts
- **Language:** Python 3
- **Framework:** Pygame
- **Concepts:** Object-Oriented Programming (OOP), Inheritance, File System Automation, Vector Mechanics, Game Loop Design.

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the directory:
   ```bash
   cd Warrior-Platformer
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the game:
   ```bash
   python main.py
   ```
